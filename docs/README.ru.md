# Iron Nest Ballistics Calculator

[English](../README.md) · [繁體中文](README.zh-TW.md) · [简体中文](README.zh-CN.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Português (Brasil)](README.pt-BR.md) · [Українська](README.uk.md) · [日本語](README.ja.md) · Русский · [한국어](README.ko.md) · [Čeština](README.cs.md) · [Polski](README.pl.md) · [Italiano](README.it.md) · [Español (Latinoamérica)](README.es-419.md) · [Türkçe](README.tr.md)

Баллистический калькулятор, созданный на Vue 3 + TypeScript + Vite. Он вычисляет расстояние, азимут, угол возвышения, время полёта и время выстрела по координатам орудия и цели, а также управляет очередью стрельбы для двух орудий. Интерфейс поддерживает 16 языков.

## Использование

1. **Установите позицию орудия**: нажмите кнопку «Gun Position» вверху экрана и выберите блок (A–T), строку (1–10) и подкоординаты (X/Y, 0–9) во всплывающем окне.
2. **Установите координаты цели**: на панели «Target Position» введите координаты цели таким же образом.
3. **Выберите заряд**: выберите значение заряда от 1 до 6. Варианты, превышающие текущую дальность (каждый заряд достигает максимум 5 км), автоматически отключаются, а выбор переключается на допустимое значение, если расстояние изменится и превысит его.
4. **(Необязательно) Установите время поражения цели**: откройте настройки (значок шестерёнки) и включите «Enable impact time / fire time», затем введите время поражения цели (24-часовой формат) в поле «Target Impact Time» — результат вычислит соответствующее время выстрела.
5. **Посмотрите результаты**: панель «Results» показывает в реальном времени:
   - **Distance**: расстояние между орудием и целью (км)
   - **Azimuth**: азимут в градусах
   - **Elevation**: угол возвышения
   - **Flight Time**: время полёта снаряда в секундах (требуется включённое время поражения)
   - **Fire Time**: время, когда нужно стрелять (требуется включённое время поражения)
6. **Добавить в очередь стрельбы**: нажмите «Load Gun 1» или «Load Gun 2», чтобы сохранить текущие координаты цели, заряд, азимут, угол возвышения и (если включено) время выстрела/поражения в очередь этого орудия (до 5 записей на каждое). На панели очереди можно отметить запись как выполненную или удалить её.
7. **Сменить язык**: используйте меню языка в правом верхнем углу, чтобы изменить язык интерфейса; выбор сохраняется в браузере и запоминается при следующем открытии.

## Настройка окружения разработки

```bash
npm install
npm run dev
```

Другие команды:

```bash
npm run build      # Проверка типов и сборка для продакшена
npm run preview    # Предпросмотр продакшен-сборки
npm run lint        # Проверка стиля кода
npm run lint:fix    # Автоматическое исправление проблем стиля
npm run format      # Форматирование Prettier и исправление проблем lint
```
