Балістичний калькулятор, створений на Vue 3 + TypeScript + Vite. Він обчислює відстань, азимут, кут піднесення, час польоту та час пострілу за координатами гармати й цілі, а також керує чергою пострілів для двох гармат. Інтерфейс підтримує 16 мов.

## Використання

1. **Встановіть позицію гармати**: натисніть кнопку «Gun Position» у верхній частині екрана та виберіть блок (A–T), рядок (1–10) і підкоординати (X/Y, 0–9) у спливному вікні.
2. **Встановіть координати цілі**: на панелі «Target Position» введіть координати цілі так само.
3. **Виберіть заряд**: оберіть значення заряду від 1 до 6. Варіанти, що перевищують поточну дальність (кожен заряд досягає максимум 5 км), автоматично вимикаються, а вибір переходить на дійсне значення, якщо відстань зміниться і перевищить його.
4. **(Необов'язково) Встановіть час враження цілі**: відкрийте налаштування (значок шестерні) та увімкніть «Enable impact time / fire time», потім введіть час враження цілі (24-годинний формат) у полі «Target Impact Time» — результат обчислить відповідний час пострілу.
5. **Перегляньте результати**: панель «Results» показує в реальному часі:
   - **Distance**: відстань між гарматою та ціллю (км)
   - **Azimuth**: азимут у градусах
   - **Elevation**: кут піднесення
   - **Flight Time**: час польоту снаряда в секундах (потребує ввімкненого часу враження)
   - **Fire Time**: час, коли слід стріляти (потребує ввімкненого часу враження)
6. **Додати до черги пострілів**: натисніть «Load Gun 1» або «Load Gun 2», щоб зберегти поточні координати цілі, заряд, азимут, кут піднесення та (якщо ввімкнено) час пострілу/враження в чергу цієї гармати (до 5 записів кожна). На панелі черги можна позначити запис як здійснений або видалити його.
7. **Змінити мову**: скористайтеся меню мови у верхньому правому куті, щоб змінити мову інтерфейсу; вибір зберігається в браузері та запам'ятовується наступного разу.

## Налаштування розробки

```bash
npm install
npm run dev
```

Інші команди:

```bash
npm run build      # Перевірка типів і збірка для продакшену
npm run preview    # Перегляд продакшн-збірки
npm run lint        # Перевірка стилю коду
npm run lint:fix    # Автоматичне виправлення проблем стилю
npm run format      # Форматування Prettier і виправлення проблем lint
```
